# 나만의 퀴즈 게임 (Python)

## 📌 프로젝트 개요
Python 기본 문법과 객체 지향 프로그래밍(OOP)을 활용하여 터미널에서 동작하는 퀴즈 게임을 구현한 프로젝트입니다.

## 🎯 퀴즈 주제 선정 이유
**선정 주제: 파이썬(Python) 프로그래밍 기초**
파이썬 언어를 학습하면서 이 프로그램을 작성하고 있기 때문에, 스스로 배운 내용을 점검하고 복습하기 위해 파이썬 기초 문법과 관련된 퀴즈를 주제로 선정했습니다.

## 🚀 실행 방법
이 프로그램은 Python 3.10 이상의 환경에서 외부 라이브러리 없이 실행 가능합니다.
```bash
# 터미널에서 아래 명령어를 입력하여 실행합니다.
python main.py
```

## ✨ 기능 목록
1. **퀴즈 풀기**: 저장된 퀴즈를 순서대로(또는 랜덤하게) 풀고 결과를 확인합니다.
2. **퀴즈 추가**: 새로운 퀴즈 문제, 선택지(4개), 정답을 직접 등록합니다.
3. **퀴즈 목록**: 등록된 전체 퀴즈 목록을 확인합니다.
4. **점수 확인**: 게임을 진행하며 달성한 최고 점수를 확인합니다.
5. **종료**: 프로그램을 안전하게 종료하며, 입력 오류를 방어합니다.

## 💾 데이터 파일 설명 (`state.json`)
- **경로**: 프로젝트 루트 경로 (`Python_QuizGame/state.json`)
- **역할**: 사용자가 추가한 퀴즈 데이터와 최고 점수를 저장하여 프로그램을 종료해도 데이터가 유지되도록 합니다. (데이터 영속성)
- **필드 구조 (스키마)**:
  ```json
  {
      "quizzes": [
          {

              "answer": 3
          }
      ],
      "best_score": 0
  }
  ```
